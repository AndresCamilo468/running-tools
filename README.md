# Running Tools

Herramientas sencillas para running, en una sola página web estática.

- **Tabla de paces**: pace por km o milla, velocidad y tiempo esperado en 1K, 5K, 10K, media maratón y maratón. Por defecto va de 3:45 a 7:00 /km cada 5 s; puedes buscar tu pace y cambiar el rango y el paso.
- **Mapa de objetivos**: gráfico con el pace necesario para bajar de las marcas clásicas (sub 20′ en 5K, sub 3h30 en maratón…). Al tocarlo se busca ese pace en la tabla.
- **Calculadora**: escribe dos de distancia, tiempo y pace, y el tercero se calcula solo.
- **Predicción de carreras y ritmos de entrenamiento**: a partir de una marca, estima tus tiempos en otras distancias (fórmula de Riegel) y tus rangos de pace suave, maratón, umbral, intervalos y repeticiones.

Sin dependencias ni build: todo está en `index.html`. Se publica con GitHub Pages.
